# Aturan Git

- **Jangan commit otomatis.** Jangan jalankan `git commit` kecuali pengguna secara eksplisit memintanya.
- Setelah mengubah file, tampilkan ringkasan perubahan (file apa saja dan apa yang berubah), lalu tunggu pengguna meminta commit.
- Jangan `git push` tanpa permintaan eksplisit.
- Jangan membuat pull request kecuali diminta.
- Jangan menghapus branch atau file tanpa permintaan eksplisit.
- Kalau pengguna meminta commit, ikuti `templates/commit.md`.
